ادارة الجوامع
أولاً: لوحة تحكم مدير المدرسة

تعتبر لوحة المدير مركز التحكم الرئيسي، وتحتوي عادةً على:

1. الصفحة الرئيسية (Dashboard)
   عدد الطلاب.
   عدد المعلمين.
   عدد الصفوف والشعب.
   نسبة الحضور والغياب.
   آخر الإشعارات.
   أحدث الأنشطة داخل المدرسة.
   إحصائيات سريعة عن الأداء.
2. إدارة الطلاب

يمكن للمدير:

إضافة طالب جديد.
تعديل بيانات الطالب.
نقل الطالب بين الصفوف.
حذف أو أرشفة الطالب.
البحث عن أي طالب.
عرض الملف الأكاديمي للطالب.
متابعة درجاته وحضوره. 3. إدارة المعلمين

تشمل:

إضافة معلم جديد.
تعديل بياناته.
تحديد المواد التي يدرسها.
تعيين الصفوف والشعب.
منح الصلاحيات.
متابعة الحضور.
متابعة الأداء. 4. إدارة الصفوف والشعب
إنشاء صف جديد.
إنشاء شعبة.
توزيع الطلاب.
ربط المعلمين بالصفوف. 5. إدارة المواد الدراسية
إضافة مادة.
تعديل المادة.
حذف المادة.
تحديد عدد الحصص الأسبوعية.
تعيين معلم المادة. 6. الجداول الدراسية

يمكن للمدير:

إنشاء جدول الحصص.
تعديل الجدول.
طباعة الجدول.
توزيع الحصص على المعلمين. 7. الحضور والغياب

يشمل:

متابعة حضور الطلاب.
متابعة حضور المعلمين.
استخراج تقارير الغياب.
معرفة المتأخرين. 8. الامتحانات
إنشاء اختبار.
تحديد تاريخه.
تحديد المادة.
تحديد الصف المستهدف.
متابعة النتائج. 9. الدرجات
مراجعة درجات الطلاب.
اعتماد النتائج.
استخراج كشوف الدرجات.
طباعة الشهادات. 10. التقارير

مثل:

تقرير الطلاب.
تقرير المعلمين.
تقرير الحضور.
تقرير الغياب.
تقرير النتائج.
تقرير الأداء العام. 11. الإعلانات

يمكن للمدير:

إرسال إعلان لجميع المدرسة.
إرسال إعلان لصف معين.
إرسال إعلان للمعلمين.
إرسال إعلان لأولياء الأمور. 12. إدارة الحسابات والصلاحيات
إنشاء مستخدمين.
تعديل كلمات المرور.
تحديد صلاحيات كل مستخدم.
إدارة أدوار النظام.

ثانياً: لوحة تحكم الأستاذ (المعلم)

بعد تسجيل الدخول تظهر لوحة خاصة بالمعلم.

1. الصفحة الرئيسية

تحتوي على:

جدول اليوم.
عدد الحصص.
الإشعارات.
الواجبات المطلوب تصحيحها.
آخر الأخبار. 2. الجدول الدراسي

يعرض:

الحصص اليومية.
الصفوف.
الشعب.
أوقات الحصص. 3. تسجيل الحضور

يمكن للمعلم:

تسجيل حضور الطلاب.
تسجيل الغياب.
تسجيل التأخر.
تعديل السجل عند الحاجة. 4. الواجبات

يمكن للمعلم:

إنشاء واجب.
رفع ملفات.
تحديد موعد التسليم.
تصحيح الواجبات.
إضافة ملاحظات. 5. الامتحانات

يشمل:

إنشاء اختبار.
إدخال الأسئلة (إن كانت المنصة تدعم ذلك).
تحديد موعد الامتحان.
تصحيح النتائج. 6. إدخال الدرجات

يقوم المعلم بـ:

إدخال درجات الطلاب.
تعديل الدرجات.
حفظ النتائج.
إرسالها للإدارة لاعتمادها. 7. إدارة الدروس

يمكن للمعلم:

إضافة درس.
رفع ملفات PDF.
رفع عروض PowerPoint.
إضافة فيديوهات.
إضافة روابط تعليمية. 8. الرسائل والإشعارات

يمكن للمعلم:

إرسال رسالة للإدارة.
إرسال رسالة للطلاب.
إرسال رسالة لأولياء الأمور.
استقبال التنبيهات. 9. الملف الشخصي

يشمل:

تعديل البيانات الشخصية.
تغيير كلمة المرور.
تحديث رقم الهاتف والبريد الإلكتروني.
