# Task 03 — Seeders

## 3.1: Create GovernorateCitySeeder

**File:** `database/seeders/GovernorateCitySeeder.php`

This seeder populates all 14 Syrian governorates and their cities.

**Governorates and cities data:**

| Governorate | Cities |
|-------------|--------|
| دمشق | دمشق |
| ريف دمشق | ريف دمشق, دوما, داريا, جرمانا, صحنايا, قطنا, النبك, يبرود, الزبداني, معرة النعمان (wait—that's Idlib), التل, جديدة الفضل, الكسوة |
| حلب | حلب, منبج, عفرين, الباب, جرابلس, السفيرة, اعزاز, عين العرب |
| حمص | حمص, تدمر, القصير, الرستن, تلكلخ |
| حماة | حماة, سلمية, مصياف, السقيلبية, محردة |
| اللاذقية | اللاذقية, جبلة, القرداحة, الحفة |
| طرطوس | طرطوس, بانياس, صافيتا, الشيخ بدر, الدريكيش |
| دير الزور | دير الزور, الميادين, البوكمال, هجين |
| الحسكة | الحسكة, القامشلي, المالكية, رأس العين, عامودا |
| الرقة | الرقة, الثورة, تل ابيض, الطبقة |
| إدلب | إدلب, معرة النعمان, جسر الشغور, أريحا, سرمين |
| درعا | درعا, ازرع, الصنمين, نوى, طفس |
| السويداء | السويداء, شهبا, صلخد |
| القنيطرة | القنيطرة, خان أرنبة |

**Implementation:**

```php
class GovernorateCitySeeder extends Seeder
{
    public function run(): void
    {
        $governorates = [
            'دمشق' => ['دمشق'],
            'ريف دمشق' => ['دوما', 'داريا', 'جرمانا', 'صحنايا', 'قطنا', 'النبك', 'يبرود', 'الزبداني', 'التل', 'جديدة الفضل', 'الكسوة'],
            'حلب' => ['حلب', 'منبج', 'عفرين', 'الباب', 'جرابلس', 'السفيرة', 'اعزاز', 'عين العرب'],
            'حمص' => ['حمص', 'تدمر', 'القصير', 'الرستن', 'تلكلخ'],
            'حماة' => ['حماة', 'سلمية', 'مصياف', 'السقيلبية', 'محردة'],
            'اللاذقية' => ['اللاذقية', 'جبلة', 'القرداحة', 'الحفة'],
            'طرطوس' => ['طرطوس', 'بانياس', 'صافيتا', 'الشيخ بدر', 'الدريكيش'],
            'دير الزور' => ['دير الزور', 'الميادين', 'البوكمال', 'هجين'],
            'الحسكة' => ['الحسكة', 'القامشلي', 'المالكية', 'رأس العين', 'عامودا'],
            'الرقة' => ['الرقة', 'الثورة', 'تل ابيض', 'الطبقة'],
            'إدلب' => ['إدلب', 'معرة النعمان', 'جسر الشغور', 'أريحا', 'سرمين'],
            'درعا' => ['درعا', 'ازرع', 'الصنمين', 'نوى', 'طفس'],
            'السويداء' => ['السويداء', 'شهبا', 'صلخد'],
            'القنيطرة' => ['القنيطرة', 'خان أرنبة'],
        ];

        foreach ($governorates as $govName => $cities) {
            $governorate = Governorate::create(['name' => $govName]);

            foreach ($cities as $cityName) {
                City::create([
                    'name' => $cityName,
                    'governorate_id' => $governorate->id,
                ]);
            }
        }
    }
}
```

- Use `Governorate::create()` and `City::create()` with UUIDs auto-generated by `UuidTrait`
- All seed data is hardcoded (user chose "Seeder only")

## 3.2: Update TenantSeeder — backfill governorate_id and city_id

**File:** `database/seeders/TenantSeeder.php`

Add a step after the existing backfill logic to match old `city` strings to actual `city_id` and `governorate_id`:

```php
// Backfill governorate_id and city_id from city string
$tenantsWithoutGovernorate = DB::table('tenants')
    ->whereNotNull('city')
    ->whereNull('governorate_id')
    ->get();

foreach ($tenantsWithoutGovernorate as $tenant) {
    $city = City::where('name', $tenant->city)->first();
    if ($city) {
        DB::table('tenants')->where('id', $tenant->id)->update([
            'city_id' => $city->id,
            'governorate_id' => $city->governorate_id,
        ]);
    }
}

$usersWithoutGovernorate = DB::table('users')
    ->whereNotNull('city')
    ->whereNull('governorate_id')
    ->get();

foreach ($usersWithoutGovernorate as $user) {
    $city = City::where('name', $user->city)->first();
    if ($city) {
        DB::table('users')->where('id', $user->id)->update([
            'city_id' => $city->id,
            'governorate_id' => $city->governorate_id,
        ]);
    }
}
```
